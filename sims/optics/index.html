Quick reference

  • Lens formula 1/f = 1/v − 1/u
  • Mirror formula 1/f = 1/v + 1/u
  • Magnification m = v/u (lens), m = −v/u (mirror)
  • Sign convention Real-is-positive for distances
  • Converging convex lens, concave mirror (f > 0)
  • Diverging concave lens, convex mirror (f < 0)

About Ray Optics

  1. Choose an element. Use the toolbar to switch between convex lens, concave lens, concave mirror, and convex mirror.
  2. Drag the object. Click and drag the yellow arrow to change the object distance. The three principal rays update in real time.
  3. Adjust focal length. Use the slider below the canvas to change the focal length of the element.
  4. Read the analysis. The side panel shows object distance, image distance, magnification, and image nature (real/virtual, upright/inverted).
  5. Ray colors. Red ray is parallel then through focus. Green ray passes through the center. Blue ray goes through focus then exits parallel.
  6. Practice mode. Switch to Practice to solve randomly generated optics problems — find image distance, magnification, or focal length.
Tip: Try dragging the object past the focal point of a convex lens to see the image flip from virtual to real!
